IEPD Instructions:

1) Read the NGRel1.7Bankruptcy_IEPD_document.pdf in the Documentation folder for XML interface exchange details and the changelog.xml for changes to IEPD package.

2) Open the mpd-catalog.xsl and catalog.xml files in your web browser to view the contents of this Information Exchange Package Description zip file.  

3) NGRel1.7_Individual_BK_Business_Rules.xlsx file contains mapping of each PDF form field to the XML node in an XML example file.

4) XML sample files are provided to assit you creating an XML file that can be submitted to open a bankruptcy case. 
They validate against the bankruptcy schema file 
/exchange_files/schema/constraint/niem/extension/BankruptcyPetition.xsd
 
5) Go to the NIEM.gov website for more general information on this XML standard, the National Information Exchange Model:

https://www.niem.gov/aboutniem/Pages/niem.aspx
